📱 PhonePe Transaction Analysis Dashboard | Power BI

📌 Project Overview

The PhonePe Transaction Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI to analyze digital payment transactions, transaction values, customer behavior, and payment success rates.

The dashboard transforms transaction data into meaningful business insights through interactive visualizations, KPI cards, charts, and slicers. It helps understand transaction trends, user engagement, service performance, and customer demographics to support data-driven decision-making.

🎯 Project Objectives

- Analyze total transactions and overall transaction value.
- Monitor payment success rates and transaction performance.
- Understand monthly transaction trends and growth.
- Identify high-value users based on transaction value.
- Compare transaction performance across different services.
- Analyze customer age groups and their contribution.
- Compare weekday and weekend transaction patterns.
- Create an interactive dashboard for business reporting and analysis.

🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and data visualization.
- Microsoft Excel – Data preparation and initial data analysis.
- DAX (Data Analysis Expressions) – KPI calculations, measures, and growth analysis.
- Power Query – Data cleaning and transformation.
- Data Visualization – Interactive charts, KPI cards, slicers, and business insights.

📊 Key Performance Indicators (KPIs)

The dashboard tracks the following key metrics:

- Total Transactions: 300K
- Total Transaction Value: ₹3.47 billion
- Unique Users: 108K
- Successful Transaction Rate: 96%
- Month-over-Month Growth: Displayed through KPI cards.

Note: These figures represent the values displayed in the project dashboard and are based on the dataset used for this analysis.

📈 Dashboard Features

1. Transaction Performance Analysis

Analyzes monthly transaction volumes and transaction values to identify trends, fluctuations, and changes in payment activity.

2. Service Transaction Value Analysis

Compares transaction values across different services, including:

- Loans
- Insurance
- Money Transfers
- Recharge Services

This analysis helps identify services contributing the most to total transaction value.

3. Customer Demographic Analysis

Examines the contribution of different age groups:

- Generation Z
- Millennials
- Generation X
- Baby Boomers

This helps understand the distribution of transaction activity across customer segments.

4. Top 5 Users Analysis

Identifies the five highest-value users based on transaction value, helping demonstrate customer-level transaction analysis.

5. Weekday vs. Weekend Analysis

Compares transaction activity on weekdays and weekends to understand customer payment behavior and usage patterns.

6. Interactive Filters

The dashboard includes slicers for:

- Month
- Service
- Payment Status

These filters allow users to explore transaction data dynamically.

7. Business Insights

The dashboard highlights key observations related to service performance, transaction patterns, and customer demographics to support business analysis.

💡 Key Business Insights

Based on the dashboard visualizations:

1. High Transaction Volume: The dashboard records approximately 300K transactions, providing an overview of payment activity.
2. Strong Payment Success Rate: The displayed success rate of 96% indicates a high proportion of successful transactions.
3. Service-Level Performance: Loans contribute the highest transaction value among the services displayed.
4. Customer Segmentation: Generation X and Millennials account for substantial shares of the displayed age-segment contribution.
5. Weekday Usage Patterns: The dashboard indicates higher transaction activity on weekdays than on weekends.
6. Monthly Trend Analysis: Monthly comparisons help identify changes in transaction volume and transaction value.
7. Customer-Level Analysis: The top-five-user visualization highlights customers with the highest transaction values.
8. Performance Monitoring: KPI cards provide a quick overview of transaction volume, transaction value, unique users, and payment success rate.

These insights describe the dashboard's displayed results and should be validated against the underlying data before being used for actual business decisions.

🎬 Netflix Data Analysis Dashboard | Power BI

📌 Project Overview

This project presents an interactive Netflix Dashboard built using Microsoft Power BI to analyze Netflix's content library, including movies, TV shows, genres, ratings, countries, and content release trends.

The dashboard transforms raw Netflix data into meaningful visualizations and KPIs to help users understand content distribution, popular genres, audience ratings, and content growth over time.

🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows on Netflix.
- Identify the most popular genres available on the platform.
- Understand content ratings across different content types.
- Explore Netflix's content library by country and release year.
- Track content addition trends over time.
- Build an interactive dashboard using KPIs, charts, and slicers.

🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and data visualization
- Power Query – Data cleaning and transformation
- DAX (Data Analysis Expressions) – KPI calculations and measures
- Excel / CSV – Dataset storage and data preparation

📊 Dashboard Features

1. Key Performance Indicators (KPIs)

The dashboard displays important metrics, including:

- Total Titles
- Total Genres
- Average Movie Runtime
- Total Movies
- Total TV Shows
- Total Countries
- Average TV Show Rating

2. Movie vs. TV Show Distribution

A donut chart compares the number and percentage of Movies and TV Shows available in the dataset.

3. Ratings by Content Type

A bar chart compares content ratings across Movies and TV Shows to highlight the distribution of Netflix titles by rating category.

4. Top Genres on Netflix

A horizontal bar chart identifies the most frequently represented genres, helping users understand the composition of Netflix's content library.

5. Content Added Over Time

An area chart visualizes Netflix content additions over the years, highlighting changes in the volume of titles added to the platform.

6. Interactive Filters

The dashboard includes slicers for:

- Content Type
- Country
- Release Year
- Date Added

These filters allow users to explore the data dynamically and compare different segments of Netflix's content library.

💡 Key Business Insights

- Movies represent a larger share of the titles in the dataset than TV Shows.
- The dataset contains a diverse range of genres, reflecting Netflix's varied content library.
- Drama and international content genres feature prominently in the genre distribution.
- Content ratings help identify the composition of Netflix's library across different audience categories.
- The content addition trend shows a substantial increase in titles during the later years represented in the dataset.
- Interactive filters make it easier to explore content by country, type, release year, and addition date.

Note: These insights are based on the dashboard visualizations. They describe the dataset and should not be interpreted as verified information about Netflix's current catalog.

🍊 Swiggy Sales Analysis Dashboard | Microsoft Excel

📌 Project Overview

This project presents an interactive Swiggy Sales Analysis Dashboard built using Microsoft Excel to analyze sales performance, customer ratings, order trends, and regional sales distribution. The dashboard transforms raw data into meaningful business insights through interactive visualizations, KPI cards, and data-driven analysis.

The objective of this project is to understand business performance, identify sales trends, and support data-driven decision-making.

🎯 Project Objectives

- Analyze overall sales performance and order volume.
- Track average customer ratings and rating distribution.
- Identify monthly and quarterly sales trends.
- Compare sales performance across different days of the week.
- Analyze city-wise sales performance.
- Visualize geographical sales distribution across Indian states.
- Present key performance indicators through a professional dashboard.

📊 Key Performance Indicators (KPIs)

The dashboard highlights the following metrics:

- Total Sales: ₹53.01M
- Average Rating: 4.34
- Average Order Value: ₹268.51
- Ratings Count: 5.59M
- Total Orders: 197,430K (as displayed in the dashboard; the underlying data should be verified to confirm the correct unit and value).

📈 Dashboard Features

1. Monthly Sales Trend

Visualizes monthly sales performance from January to August, helping identify fluctuations and changes in revenue over time.

2. Customer Rating Distribution

Displays the distribution of ratings, providing an overview of customer feedback and satisfaction.

3. Day-wise Sales Analysis

Compares sales across different days of the week to identify high-performing and low-performing days.

4. Quarterly Performance Analysis

Summarizes quarterly sales, customer ratings, and order volumes to compare business performance across quarters.

5. State-wise Sales Distribution

Uses a geographical map to visualize sales distribution across Indian states and identify regional performance differences.

6. Top 5 Cities by Sales

Highlights the five leading cities by sales, helping identify important markets and potential areas for business growth.
